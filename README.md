# Sham Ashik | Performance Marketing Portfolio

This is a static HTML/CSS portfolio deployable directly from the repository root on Vercel.

## Vercel configuration
- Framework preset: Other
- Root directory: `./`
- Build command: None (override disabled)
- Output directory: `.` (or leave blank when the dashboard accepts it)
- Install command: None

`index.html`, `styles.css`, and `vercel.json` all live at the repository root. No npm build is required.

The ZIP is retained as an archive. Case study summaries are live in the site; downloadable PDF/CV files and slide screenshots are not yet published as separate assets.
